LM Knob

La Marzocco Linea Micra — cloud controller

  1. Branchez le board en USB
  2. Cliquez Install ci-dessus
  3. Sélectionnez le port série dans la popup
  4. Attendez la fin du flash (~30 s)
  5. Au démarrage, connectez-vous au Wi-Fi LM-Knob-Setup
  6. Ouvrez 192.168.4.1 et entrez vos credentials

Requiert Chrome ou Edge (Web Serial API).
