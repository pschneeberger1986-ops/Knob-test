☕ LM Knob

Standalone La Marzocco controller for the Guition JC3636K718C

Compatible hardware

Guition JC3636K718C Linea Micra Linea Mini GS3

No Home Assistant required · No cloud required after first pairing · Bluetooth local control only

How to flash

  1. Connect your Guition board to your PC via USB.
  2. Click Flash firmware below (Chrome or Edge required — Web Serial API).
  3. Select the correct COM/serial port when prompted.
  4. Wait ~60 s for the firmware to install.
  5. The device reboots and shows the setup screen.

Requires Chrome or Edge 89+.
On Linux, add your user to the dialout group.

After flashing – pairing your machine

  1. The knob displays a setup screen on first boot.
  2. Put your La Marzocco in pairing mode (hold the button until the LED blinks blue).
  3. Press the knob — the device scans and pairs automatically. The BLE token is stored on the device.
  4. Done! The knob shows live temperature and status.

Wi-Fi is optional (used only for OTA firmware updates). If you connect to the LM-Knob-Setup Wi-Fi AP after flashing, you can enter your network credentials via a browser at 192.168.4.1.

Controls

  1. Short press — toggle machine on / standby
  2. Long press — open settings (coffee temp, steam level)
  3. Rotate (in settings) — adjust value
  4. Press (in settings) — confirm & next
